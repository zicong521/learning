# Zicong Personal Site

A static GitHub Pages personal introduction page about engineering, long-term investing research, and financial-report analysis automation.

## Local preview

Open `index.html` directly in a browser. No build step is required.

## Deploy

The repository includes `.github/workflows/pages.yml`. After this branch is merged into `master`, enable GitHub Pages with **Source: GitHub Actions** in the repository settings, then run the workflow or push to `master`.

Expected URL after Pages is enabled:

<https://zicong521.github.io/learning/>
